Why it's different

Reviews you can actually trust.

Evidence or it didn't happen

Every finding must quote the exact line. If the quote isn't in your file, it's discarded as a hallucination — and line numbers are corrected to match.

Reviews your diff, not your repo

Point it at staged changes or a PR and it reports only the lines you touched, using the rest of the file for context. Old problems stay quiet.

Private by default

Runs on a local Ollama model. Your code never leaves your machine, there's no API key to leak, and results are cached so unchanged code is instant.
